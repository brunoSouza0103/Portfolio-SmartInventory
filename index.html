01 / SOBRE O PROJETO

Um estoque mais simples de entender.

Uma proposta de sistema para dar visibilidade às informações e às movimentações de estoque.

O DESAFIO
⌕

Informação dispersa dificulta o controle.

Registros manuais ou espalhados podem dificultar a consulta de quantidades, o acompanhamento das movimentações e a identificação de itens que precisam de reposição.

O OBJETIVO
◎

Centralizar o controle de estoque.

O SmartInventory busca reunir o cadastro de produtos e o registro de entradas e saídas, facilitando o acompanhamento do estoque e o acesso às informações.

TECNOLOGIAS
⌘

Stack do projeto

Aplicação web com frontend, API backend e persistência relacional.

Frontend: React + ViteBackend: Java + Spring BootBanco: PostgreSQL

VISÃO DA SOLUÇÃO

Do registro à consulta, em um fluxo organizado.

O frontend em React e Vite consome os serviços do backend em Java com Spring Boot, que utiliza PostgreSQL para persistir os dados do inventário.
